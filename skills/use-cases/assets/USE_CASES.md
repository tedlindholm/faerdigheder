## Not built yet

Behaviour that does not exist yet starts here as a draft, before any code.

1. **Draft it below** as a level-3 heading with the outcome sentence, no ID, and the same sections as the template: Given, When, Then, and a sketch or the rule.
2. **Build it test-first.** Write the failing test, then the code.
3. **Move it to the use case folder** when it is built and tested: take the next free ID there, copy the draft into a `UC-<number>-<name>.md` file, tag the tests, add it to the index and delete the draft here.
